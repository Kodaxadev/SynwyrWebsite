Give AI eyes and hands inside 3D tools.

Synwyr is the control layer between an AI agent and Blender or Unity. It lets the model inspect a scene, make structured changes, verify what actually happened, and roll back safely when something is wrong.

HOW IT WORKS

See. Act. Verify.

Normal automation sends commands. Synwyr closes the loop so the agent can understand the scene before and after every meaningful change.

01PERCEPTION

See the scene.

Read objects, IDs, editor state, capabilities, revisions, and visual evidence before touching anything.

scene.snapshotviewport.capture
02ACTION

Make a bounded change.

Use structured, editor-native operations against the scene revision the agent actually inspected.

transaction.beginmesh.modify
03PROOF

Check the result.

Inspect again. Validate state and pixels. Commit the good result—or roll back and prove restoration.

mesh.validatecommit / rollback

WHY SYNWYR

A bridge is easy.
Trust is harder.

A raw MCP bridge can expose buttons and commands. Synwyr is being designed for the harder problem: giving an autonomous model enough state, identity, evidence, and recovery guarantees to work reliably inside a changing 3D project.

Read the architecture ↗
01
◎

It knows what it touched.

Persistent object identity and scene revisions replace fragile guesses based on names or stale indices.

02
◇

It fails stale edits safely.

If the editor changed since inspection, revision-aware operations can reject the mutation instead of editing unknown state.

03
✓

It proves more than success.

An API call completing is not treated as proof of quality. Machine state and visual evidence still have to agree.

04
↶

It can prove recovery.

Transactions track pre-edit state so rollback can be verified instead of simply reporting that an undo command ran.

CURRENT STATE

Built foundation-first.

Synwyr is active engineering work, not a finished autonomy claim. Blender has the strongest closed-loop implementation today. Unity parity and broader production modeling coverage are still being expanded and verified.
