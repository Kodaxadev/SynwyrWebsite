THE CONTROL LOOP

Perceive. Author. Prove.

Synwyr turns 3D creation into an evidence-driven loop: perceive the world, reason about a bounded change, author it through native tools, verify the result, correct bad hypotheses, and keep only proven state.

01
PERCEPTION DOMAIN

Ground the model in the real scene.

Object identity, revisions, capabilities, camera state, geometry, references, and visual evidence become explicit inputs—not assumptions.

scene.snapshotperception.capture_bundle→ grounded evidence
02
AUTHORING DOMAIN

Change only what the agent actually inspected.

Typed host operations execute against the expected scene revision with explicit targets, editor-native semantics, and bounded edit locality.

transaction.beginauthor.execute→ candidate state
03
TRUTH DOMAIN

Re-observe before accepting the result.

Geometry, spatial relationships, reference agreement, pattern coverage, locality, and visual evidence are measured. Bad hypotheses become correction trajectories; proven state survives.

truth.evaluatecommit / rollback→ verified result
