THE AGENT LOOP

From intent to verified 3D work.

Synwyr turns 3D creation into an evidence-driven loop. The model can inspect what exists, form a spatial hypothesis, author a bounded change, measure what actually happened, and keep correcting until the result is good enough to ship.

01PERCEPTION

Build a machine-readable world model.

Combine authoritative scene state with geometry, topology, bounds, object identity, canonical views, depth, normals, IDs, references, and declared uncertainty.

scene + geometryvisual evidence
02AUTHORING

Work through native 3D operations.

Create and modify objects, meshes, materials, scenes, assets, and editor state through typed host capabilities inside revision-pinned transactions—not giant generated scripts.

typed operationsbounded locality
03VERIFICATION

Prove the result before it survives.

Check hard geometry invariants, spatial relationships, reference agreement, repeated patterns, coverage, and edit blast radius. Commit what passed. Roll back what did not.

deterministic truthcommit / rollback
MODEL→SYNWYR→3D HOST→TRUTH→CORRECTION→VERIFIED RESULT
THE SYSTEM

Not another Blender chatbot. A control plane for spatial agents.

Synwyr is designed to become the layer that lets any sufficiently capable model operate inside a live 3D production environment with the context, precision, memory, and recovery discipline that one-shot generation lacks.

Spatial perception

Semantic scene graphs and visual evidence belong in the same reasoning loop: objects, parts, transforms, topology, depth, normals, silhouettes, references, and what remains unknown.

Native authoring

The model works through composable editor-native capabilities with stable identities and explicit coordinate contracts, while raw code remains an escape hatch rather than the product surface.

03
✓

Deterministic 3D truth

Geometry validity, dimensions, reference shape, pattern consistency, coverage, locality, and before/after evidence give the agent something stronger than confidence: measurable proof.

04
↶

Reversible autonomy

Every meaningful edit can live inside a transaction. Failed hypotheses become useful trajectory data while the authored scene returns to the last verified state.

THE END STATE

One spatial intelligence layer. Any capable model. Every serious 3D workflow.

The destination is bigger than an MCP server for one editor. Synwyr is a local-first control plane where models, generators, DCCs, and game engines can share the same authoritative state, verification semantics, transaction history, and reusable skills.
